# spec-trace v1 — initial eval results (2026-05-11)

Three-arm benchmark across five hand-curated coding tasks. Reproducible
end-to-end from a fresh checkout.

> Numbers below are filled in by `evals/measure.py` after the runner
> completes. See `evals/README.md` for the methodology and `evals/fixtures/`
> for the inputs.

## Setup

- Runner: `python evals/run_eval.py --all-tasks --all-arms`.
- Model: `claude-opus-4-7[1m]` (whatever `claude --bare -p` resolves at
  the time of the run; pinned via the `claude_code_version` field in
  every session JSONL).
- Auth: `ANTHROPIC_API_KEY` via gitignored `.env.eval`. Charges go to the
  Anthropic API account named on that key.
- Isolation: every cell runs with `claude --bare` so the operator's host
  config (skills, plugins, global `CLAUDE.md`) is excluded from the
  context.
- Permissions: `--dangerously-skip-permissions` because the workdir is an
  ephemeral `tempfile.mkdtemp()` directory that's destroyed afterwards.

## Limitations and caveats

- **Small fixture set.** Five tasks is enough to surface qualitative
  differences but not enough for tight confidence intervals on the
  delta. v2 should aim for 20.
- **Single trial per cell.** No within-arm variance estimate. A future
  run should average over N≥3 trials.
- **Model nondeterminism.** Claude is stochastic; running the same arm
  twice can produce different tool-call traces. Treat per-cell numbers
  as one sample, not a population.
- **Arm B is a proxy for "advisory."** It surfaces SKILL.md via
  `--append-system-prompt-file` rather than through Claude Code's normal
  plugin discovery (which `--bare` disables). This faithfully isolates
  the *content* of the skill but may diverge slightly from how a real
  user's session would behave.
- **`expected.md` is reviewer guidance, not a test oracle.** The
  "files-out-of-scope" metric is heuristic — automated against the
  fixture's stated scope, not graded against a reference patch.
- **No human reviewer score yet.** The methodology calls for two blinded
  reviewers per arm; that's a manual step pending.

## How to reproduce

```bash
# 1. Drop your ANTHROPIC_API_KEY into .env.eval
cp .env.eval.example .env.eval
$EDITOR .env.eval

# 2. Run the full sweep (5 tasks × 3 arms, ~30 min, ~$3.50)
make eval

# 3. Generate the scorecard
python evals/measure.py evals/results/_local --out evals/results/2026-05-11.md
```

Raw session logs land in `evals/results/_local/`. They include every
tool call, every model response, and exact token counts.
